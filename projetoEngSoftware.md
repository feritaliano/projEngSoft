O projeto consiste no desenvolvimento, em equipe, de um sistema de software minimamente complexo. O projeto não deve se limitar a uma página estática ou a operações CRUD simples. O sistema deve possuir regras de negócio e comportamentos que justifiquem a aplicação de práticas de Engenharia de Software, especialmente testes automatizados.
O ideal é que o projeto possua:
- um backend com uma arquitetura organizada e adequada ao problema;
- um frontend que se comunique com o backend;
- uma interface de usuário interativa;
- regras de negócio implementadas e testadas;
- testes automatizados;
- controle de versão utilizando Git/GitHub;
documentação suficiente para permitir que outras pessoas entendam e executem o projeto.
O projeto deve ser desenvolvido de maneira incremental, com entregas frequentes ao longo do semestre.
